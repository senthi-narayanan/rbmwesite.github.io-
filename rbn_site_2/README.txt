GOLDEAN CREATIVE STUDIO

Standalone HTML, CSS, and jQuery website package.

Open index.html in a browser to view the page. The images and jQuery library are included locally, so the page does not need a network connection.

Files:
- index.html: page markup
- styles.css: visual design and responsive styles
- js/script.js: image reveal interactions
- js/jquery-3.7.1.min.js: jQuery library
- assets/: construction and branding background images
